# Steun de Jeugd — Next.js

Een schone Next.js 15 App Router setup voor de nieuwe Steun de Jeugd homepage.

## Starten

```bash
pnpm install
pnpm dev
```

Open daarna `http://localhost:3000`.

## Productiecheck

```bash
pnpm build
pnpm start
```

## Belangrijk

- Next.js is vastgezet op `15.5.24`.
- pnpm is vastgezet op `9.15.9` om verschillen tussen lokaal en Vercel te beperken.
- Er zijn geen externe fonts, image hosts of UI libraries nodig.
- Vervang de tijdelijke social links en het contactadres wanneer de definitieve gegevens bekend zijn.
